# bg-grass · 草地背景

- **标准名**：bg-grass / 草地背景 / 嫩绿草地
- **版本**：v1-draft（2026-10-10，首批试用后转正）
- **使用方**：home/farm/plaza 地面
- **图锚**：[anchors/style-tile.png](../anchors/style-tile.png) 第 1 行第 2 格

## 标准描述（prompt 引用段）

```text
嫩绿草地：明快的嫩绿色（grass/ground 系）、平缓起伏的地势、
可零星点缀小花与圆灌木；纯平无立体边、卡通 3D 黏土质感。
```

## 使用要点

- 与天空（[bg-sky.md](bg-sky.md)）衔接处为柔和地平线，无硬切边；
- 农田地块/小径等功能地形为页面定制内容，在页面 prompt 的可变段落描述；
- 大面积使用时可平铺延展（BG 规格，design-system §10 尺寸表）。
