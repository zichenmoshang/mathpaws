# resource-pill · 资源胶囊

- **标准名**：resource-pill / 资源胶囊 / 货币胶囊
- **版本**：v1-draft（2026-10-10，首批试用后转正）
- **使用方**：全站 HUD 资源位（farm/pet/gacha；pill-food/pill-shell）
- **图锚**：[anchors/style-tile.png](../anchors/style-tile.png) 第 5 行（贝壳+128 样例）

## 标准描述（prompt 引用段）

```text
白色资源胶囊：长圆角胶囊、白色釉面、左侧圆润资源图标（贝壳/食物等）、
右侧深色数字、底部浅色薄边、柔和投影；卡通 3D 黏土釉面质感。
```

## 使用要点

- 图标与数值**不 bake**：胶囊底可切图，图标引用 `i-*` 既有资产，数字一律 Web 字体
  （design-system §10.5 文字不进图）；生成整页稿时胶囊内数字允许出现但拆层时擦除登记；
- 同一画面多种资源（贝壳/食物）共用同一胶囊造型，仅换图标——防"同一需求三种实现"
  （2026-10-08 ResourcePill 收编议题的资产生）。
