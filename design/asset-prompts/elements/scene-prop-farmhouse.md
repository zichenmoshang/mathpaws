## 标准描述（prompt 引用段，以农场小屋为例）

```text
圆润农场小屋：厚圆角造型、哑光釉面、明快糖果色（屋顶与墙身取色对齐色卡）、
柔和接触阴影；与 UI 面板同一卡通 3D 黏土质感语言，不写实、不做旧。
```

## 使用要点

- **质感同源**：场景道具必须与 UI 元素同一质感语言（黏土釉面、圆角、软阴影），
  这是"同一世界观"的落地（design-system §1 核心原则）；
- 其他道具（栅栏/招牌/稻草人/作物架）参照本条改写主体名词与功能细节，
  质感段落不变；
- 道具不含文字（招牌文字 bake 是既有资产特例，新稿文字一律 Web 字体叠加）。
