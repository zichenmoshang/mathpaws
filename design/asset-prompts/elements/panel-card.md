- **使用方**：daily-chest/settings/pet/quiz 等容器（panel、panel-card、card-panel…）

## 标准描述（prompt 引用段）

```text
白色（或浅色）圆角厚边面板：大圆角、哑光釉面、底部一条深色薄边
（约面板高度的十分之一、紧贴下边缘，非独立底座层）、柔和投影；
卡片为同语言的小尺寸变体。卡通 3D 黏土质感。
```

## 使用要点

- **分层铁律**：面板/卡片是"容器"——用底部薄边（颜色线索）分离；
  浮于其上的元素（云朵底托/徽章/挂牌）用柔和投影（深度线索）；
  同一画面内不出现两条同色边（见 [title-art.md](title-art.md) 分层规则）；
- 特殊造型容器（卷轴/展台/舞台）为页面定制资产，不走本条；
- CSS 毛玻璃容器（topbar/轻量卡片）是代码语言，不生图、不适用本条。
