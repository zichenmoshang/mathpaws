## 固定段落（v1，2026-10-10 定稿，不得改动）

### 风格语言

```text
卡通 3D 黏土釉面渲染风格：圆润饱满的造型、哑光软糖质感表面、厚实圆润的描边、
柔和的软阴影与接触阴影、糖果色高饱和但不刺眼；儿童教育游戏 UI 质感；
所有元素的颜色严格对齐参考色卡（天空蓝、阳光黄、橙、草绿、红、紫、粉及其对应深色档）。
```

### 通用规则

```text
1. 按钮与卡片的底部立体厚边是紧贴元素下边缘的一条深色薄边
   （约元素高度的十分之一，像实体按钮侧面的厚度），不是独立的底座层。
2. 标题艺术字：无底托时用白描边与背景分离；有底托时去描边、文字直接坐在底托上
   （禁止描边与底托同色的"双层白"）。
3. 分离手段按层级分配：容器（面板/卡片）用底部薄边；浮于容器上的元素
   （云朵底托、徽章、挂牌）用柔和投影；同一画面内不出现两条同色边。
4. 跨页元素（宝箱/胶囊/进度条/背景/标题等）的描述引自 elements/ 圣经对应条目
   并注明版本，不自行改写。
```

### 禁止词

```text
与浅色/天空色主基调冲突的大面积深色（深蓝夜空主导；星空场景除外，
其语言引自 elements/bg-starry.md）、写实/厚涂/水彩/扁平描线风格、
文字水印、"AI生成"标记、棋盘格背景、角色或动物形象
（角色走 core-ip 图锚通道，不经页面 prompt 文字描述）。
```
