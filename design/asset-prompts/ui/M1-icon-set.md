## 二、统一视觉规范（锁定，每个图标必须一致）

对齐 gacha.png 与已批准的金色贝壳：

1. **立体厚涂卡通游戏图标（glossy 3D cartoon game icon），不是扁平风**；造型饱满圆润、有体积和厚度。
2. 表面**光滑釉面**：柔和的「亮部浅色 → 品牌主色 → 暗部深色」渐变明暗，凸起处带 **1–2 个奶白色高光点**。
3. 多数物件有圆润的**外轮廓厚度边**（比主体深一阶的同色包边）；底部带**柔和浅投影**；无外发光圈（品质框除外）。
4. 正面或轻微俯视的立体角度，居中，物件约占画面 **72%**，四周留白均匀。
5. 背景**透明**（生成是白底，后处理统一去白）；画面无任何文字、数字、logo、水印。
6. 作物种子/果实同样是**圆润 3D 卡通物件**（参考 gacha.png 的彩蛋、药水质感），非写实照片。
