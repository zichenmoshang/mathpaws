## 一、关键设计决策

1. **质感路线 = 3D 搪胶手办渲染风，而非 2D 扁平插画。**
   理由：本图要同时当 2D 立绘锚点和 3D 建模输入。搪胶盲盒产品图（纯白底、影棚光、圆润 vinyl）最利于 Hunyuan3D 还原，也符合 design-system §1/§9"角色是同一世界观的 3D 玩具、2D 页用其位图做伪 3D"，避免 2D/3D 两张皮。UI 容器才走平面糖果卡通。
2. **默认着装上下分离、极简中性**（现状高保真的背带裤、连体帽衫都是连身装，不利于"头/衣/裤/饰"四槽换装）。
3. **中性、无性别强符号**：不捏脸、不选性别（PRD §9.2 A 方案），男女童均可代入；不戴头饰（头部槽留给抽卡）。
4. **只出 1 张正面 A-pose，不做标准三视图。**
   Hunyuan3D 用单张正面图生成完整 360° 模型、不吃标准三视图；一期所有 2D 页面均为正面 / 微侧；广场侧背面由 3D 模型本身决定。确认后仅用 image_edit 衍生**正面表情套图**与**各页面立绘**，3D 建模直接用本图。若建模后侧 / 背面局部不理想，在 Blender 修模，或届时**按需**补单张背面参考，不预做整套三视图。
5. **背面友好设计**（降低单图建模侧 / 背面脑补崩坏风险）：发型前后左右对称简洁、上衣与短裤背面纯色无图案、鞋子左右对称，不放置任何仅单侧或仅背面出现的复杂装饰。
