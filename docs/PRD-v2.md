## 1. 答题与题库

### 1.1 掌握度出题完整机制
在一期路径骨架（三态 + 简单阈值解锁，见 PRD §7.7）之上补全：
- **每轮 20 题配比**：当前"学习中"知识点约 **70%** + 已掌握知识点复习约 **30%**；未解锁知识点不出题 → 天然不超纲。
- **答错处理**：该知识点继续出现，并插入相关前置知识点复习。
- 进度由掌握情况驱动、不被日历锁死：熟练孩子连续掌握即自动加速、能追上学校进度；吃力孩子停在当前知识点反复练、不掉队。
- **开学小测（定位起点）**：第一次进入正式答题前可做 5–10 题覆盖前置知识的小测（可跳过），一键定位起点；跳过则从第 1 单元起步、靠掌握度快速追赶。复用答题页 P6、不单独做整页，且不打断"选完直接进广场游玩"。
- 真实学期日历最多当一把可选"参考尺"（对比学校进度 vs 孩子进度），不做按真实日期强制推进。

### 1.2 真题大挑战（选择题）
- 形式：选择题，点选 ABC，不手写；入口 = 首页卡 2，复用答题页 P6。
- **自动生成**：计算结果选择 + 可选择化的概念辨析；干扰项按典型错误规则生成（进位 / 退位 / 数位 / 运算顺序错）。
- **概念辨析用"有限模板库 + 参数填充"，模板须经教研（用户）审核，不做纯随机**，保证题目严谨。
- 概念辨析知识点储备：周长（公式 / 长短比较 / 给长宽求周长）、年月日（大小月 / 平闰年 / 简单日期与 24 时）、小数（读写 / 比大小）、运算顺序（先算什么 / 括号作用）。
- "学奥数"后续版本再议。

### 1.3 错题本（功能基线）
> 一期已做数据层记录（写而不显，见 PRD §7.4）；二期上线即带历史数据。一期 MNIST 误判累积由 100 条上限 + 淘汰限幅，二期上线时可选一次性清洗 / "待复核"标注。

- **收录范围**：只记录正式答题做错的题。
- **去重粒度（默认）**：按 **"知识点 + 题型"去重**（同类只保留 1 条代表、累计错误次数）；**重做时生成同类新题**；容量上限约 100 条（超出淘汰最旧 / 已掌握项）。
- **错题卡**：题目 + 孩子的错误答案 + **解题思路 / 方法（分步引导、默认展示，由《知识点 - 题型 - 解法清单》驱动）**；**最终答案默认隐藏、手动点"显示答案"才出现**；**不做错误原因归因**。
- **重做**：复用同一套答题；**重做正确给贝壳、做错不给**；重做正确后移出错题本（再错则保留并刷新错误次数）。
- 入口：首页第 3 张"错题本"卡 + 结算页"有错 → 查看错题本"；数据存本地 IndexedDB。
- 扩展：间隔重复复习、掌握度统计。

### 1.4 手写样本采集
- 每次提交把"笔迹栅格图 + 识别数字 + 正确答案 + 对错"存本地 IndexedDB（strokes 表，schema 一期已保留）；识别 ≠ 正确答案标"待复核 / 潜在识别错误"、可导出，人工区分"算错 vs 识别错"后用于后续再训练。
- "识别有误"快捷反馈入口。
- 模型策略沿用一期：不无条件重训，仅明显 / 高频误判或积累足够真实儿童手写样本后再重训（流程见 `ml/mnist/README.md`）。

### 1.5 其他题型与内容
填空题、应用题（含手写最终答案）、学奥数；真题手写（MNIST 一期只服务口算）；观察物体、作图 / 测量、里程表复杂情境、"数学好玩"综合实践；名校真题库正版授权；双倍卡。
