# 角色生成规范（PaperDoll v5 · N+M 运行时合成前置约束）

> 版本：v1.0　|　最后更新：2026-10-04
> 本文回答一个问题：**新增一个可换装角色（或一顶新头饰）时，AI 生图必须满足什么几何契约，才能只产出 1 张 body（或 1 个 head）就被运行时直接复用，不需要任何逐组合手工切层。**
> 生产管线与切层算法见 [paperdoll-system.md](./paperdoll-system.md)；运行时算法见 `packages/ui/src/paperdoll-compose.ts`；全部几何常量以 `design/paperdoll-spike/step2_layers.py` 注册表为唯一事实源（2026-10-06 起不再导出 anchors.json，运行时 seam 随瘦身 manifest 发布）。

---

## 0. 为什么需要这份规范

v5 运行时模型：**N 个角色身体 + M 件头饰，组合在浏览器实时合成**（body → shoe → gear；巫师类头部按所穿身体动态 gate + 颈色 relit，见 paperdoll-system.md §7）。

生产资产只有：每角色 1 张 `body-<id>`、每件头饰 1 个 `head/hat (+mask)`、鞋全角色共用 1 双。新角色**不再需要**为每顶帽子生成 N×M 份 forhat 文件。

代价是：能这样复用，前提是所有母图共享一套严格的几何契约。**契约不满足，运行时接缝就会破**（典型症状：帽后头发鼓包、黑脸、接缝弧色差——均在 2026-10-03/04 踩过并修复，见 §6）。

## 1. 画布与机位（所有母图，硬性）

| 项 | 值 | 说明 |
|---|---|---|
| 画幅 | 2048×2048，1:1 | AI 出图即此尺寸，禁止事后拉伸/补边 |
| 背景 | 纯白 #FFFFFF，无渐变无道具 | 抠图前不得有阴影投射物；脚下软阴影允许（抠图会分离） |
| 水平中线 | cx = 1024 | 角色鼻尖 / 躯干中线落中轴，左右对称 |
| 脚底基线 | ground_y ≈ 1888 | 双脚脚底（含鞋）统一落在此线 |
| 占比 | 与现有 6 套一致 | 头身比、头顶留白、角色宽度（约 540–1640）不得漂移 |
| 机位 / 焦距 | 正面平视、正交感 | 禁止俯 / 仰 / 侧身 / 透视变化 |

## 2. 姿势（硬性，逐字写进 prompt）

标准姿势 = core-ip 正面 A-pose：

- 双臂自然下垂、向两侧微张约 15°，手在大腿外侧不贴死；
- 双脚与肩同宽、脚掌正对镜头；
- 头正、肩平、左右对称；
- **不得改动任何关节角度**——换装部件（袖、领、鞋、头层）全部按此姿态定位，姿态一变全部几何失效。

## 3. 脸部 / 发型 / 肤色（一期固定）

一期主角唯一、中性、不捏脸。所有 body 母图必须与 core-ip 一致：

- 脸：无睫毛大圆眼、同款鼻 / 嘴 / 圆耳、同款粉腮红；
- 发型：可可棕对称蓬松短发 + 头顶呆毛；
- 肤色：同一受光肤色体系。

**生图手段**：Seedream image_edit，**必须带 core-ip 参考**；脸部是漂移高发区（探险家曾被改成带睫毛眼型），prompt 须显式写"无睫毛圆眼、五官严格锚定参考图"，必要时用双参考（编辑对象 [img0] + core-ip [img1]）。

**肤色的算法边界（重要）**：运行时用固定 HSV 条带识别皮肤 / 头发（皮肤 `H 3–32, S 0.18–0.48, V≥0.62`；头发 `H 4–45, S≥0.32, V≤0.72`）。新角色若明显偏离该肤色（深肤色、非人肤色、发色为非棕色），现有条带会失效——**在把肤色参数化（按角色 manifest 下发 HSV 带）之前，不要生成该类角色**，否则巫师头 gate 与颈色 relit 会出错。

## 4. 颈部接缝契约（N+M 成败关键）

整头头饰（frog/elf/wizard）从自己的戴帽母图沿颈部水平切割，在运行时覆盖到任意 body 上。因此**新 body 的颈部必须落在既有头层的接缝区间内**：

| 头饰 | 颈切 y（cut） | 过渡带起点 y0 | 硬头区下界 hard_y = y0−2σ−1 |
|---|---|---|---|
| frog（σ=3） | 920 | 880 | **872** |
| elf（σ=3） | 985 | 945 | **937** |
| wizard（σ=8） | 1078 | 1003 | **986** |

新 body 母图必须满足：

1. **脖颈位置 / 粗细 / 下巴高度与 default body 一致**——头层是另一张 AI 图，脖子粗细差 >2-3px 接缝就会露边；
2. **衣领最高点必须低于该角色允许佩戴的头层的 hard_y**：
   - 想能戴蛙帽 → 衣领顶 < y872；精灵帽 < y937；巫师帽 < y986。
   - 高于该线的衣领 / 毛领 / 兜帽会在硬头区被运行时当身体头发擦掉（该区域源头为空气时无条件擦除）；
3. 脖颈皮肤受光正常（不要有强投影）；运行时自动从中位皮肤色采样 relit，采样范围为 y0−80 以下到画布底，因此手臂 / 小腿 / 脚的肤色也必须与脸部一致（高领角色靠这些部位取色）；
4. item 类头饰（探险家帽 ellipse / 护目镜 color）使用**固定挖洞 mask**，所以新 body 的发型 / 额头轮廓必须与现有发型一致——一期发型固定即自动满足。

> 反推：要做"高领 / 兜帽 / 新发型"的新角色，它不能戴覆盖该区域的现有头层；要么该角色禁用对应头饰（catalog 不配），要么为其新增头饰并注册新的 cut 常量（见 §8）。

## 5. 身体与鞋

- 母图为**光脚**整身（鞋全角色共用，来自独立穿鞋原图）；双脚脚型、脚掌宽度与 default 一致，脚底落 ground_y；
- 服装可以自由设计，但：轮廓不得超出角色标准宽度；不做高靴（鞋槽只有包踝低帮鞋）；不画强耦合手持 / 胸挂道具（已废弃的 acc 槽）；
- 光照：柔和影棚顶光、左右对称；质感统一为搪胶 vinyl 哑光润泽；品质色（蓝 / 紫 / 金）只走 UI，不画进服装；
- 白底生成后由管线统一抠透明（birefnet-general-lite），**母图上不要手工抠图 / 手工修像素**。

## 6. prompt 检查单（每张 body 母图生图前逐项确认）

- [ ] 输入为 image_edit + core-ip 参考（必要时双参考锚脸）；
- [ ] 2048² 白底、正面 A-pose、cx/ground_y/占比与参考一致；
- [ ] 五官 / 发型 / 肤色逐字锁定 core-ip，显式"无睫毛圆眼"；
- [ ] 光脚、脚型与基线一致；
- [ ] 衣领最高点低于目标头层 hard_y（蛙 872 / 精灵 937 / 巫师 986）；
- [ ] 颈 / 臂 / 腿脚肤色一致、无强颈影；
- [ ] 无文字 / 数字 / logo、无强性别符号、无手持物；
- [ ] prompt 已在 `design/asset-prompts/` 存档并经确认后才生成。

## 7. 新角色接入 SOP（目标：只加 1 个 body）

1. prompt 过 §6 检查单 → 用户确认 → Seedream 生成光脚白底母图；
2. 母图存 `design/paperdoll-spike/masters/dress-<id>-barefoot-nohat.png`；
3. 在 `step2_layers.py` 的 `OUTFITS` 注册一行（id / cn / series / cutout stem / prompt_doc）；
4. 跑 `step1.py` → `step2_layers.py` → `step3_zoomqc.py` → `step4_export.py` → `step5_verify_export.py`（QC）；
5. QC 验收后跑 `step6_publish.py` 发布到 `apps/web/src/assets/paperdoll/`；
6. `catalog.ts` 的 `OUTFIT_OPTIONS` 加 1 项（body URL + 图标）；
7. **回归门禁**：
   - `#paperdoll`：新身体 × 全部 5 头饰（含鞋 / 光脚）逐一点验；
   - `#paperdoll-rt`：新身体 × wizard 头的颈均值 / P95 应与现有 6 行同级（颈均值 < 3.5、P95 ≤ 16），热图允许 1–2px 接缝弧、不得有头顶鼓包 / 黑脸；
   - 不通过则回退生图，**不要为单个角色改切层脚本常量**（那会破坏既有 6 套）。

产出：生产只多 `bodies/body-<id>@2x.webp` + 1 个图标；不新增任何 forhat / per-body 文件。

## 8. 新头饰接入（不是新角色时）

1. 生成戴帽白底母图（同 §1–3 契约，脸 / 颈 / 机位与 core-ip 一致）；
2. 在 `step2_layers.py` 的 `HATS` 注册：选择 cut_mode——
   - `item`（帽 / 眼镜等小物件）：color 或 ellipse，产出帽层 + 通用 hole mask；
   - `head`（头盔 / 兜帽 / 连体帽）：注册 `HEAD_CUTS[hid]`（颈切 y，从网格放大图量取）、必要时 `HEAD_TRANSITIONS / HEAD_FEATHERS`；含深袍影颈的头走 pair（加入 `HEAD_PAIR_GATE`）；
3. step4 自动导出 seam 几何到 manifest；catalog 的 `HAT_OPTIONS` 加 1 项（pair 头带 relit 权重 0.28/0.72）；
4. 回归：全部 body × 新头过 `#paperdoll`；pair 头还要在 `#paperdoll-rt` 矩阵里补一行真值对比（离线 per-body 烘焙头由 step2 自动产到 `_truth/`）。

## 9. 已知限制（二期候选）

- 肤色 / 发色 HSV 条带硬编码：深肤色 / 非人角色需先把条带参数化进 manifest；
- 发型一期固定：真换发型需要"后发 → 脸 → 前发"多层模型，当前整头方案不支持；
- 高领 / 新轮廓角色与部分头层互斥（§4）；
- 3D 广场一期固定默认着装，不实时换装。
