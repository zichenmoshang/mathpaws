## 1. 产品概述

### 1.1 定位
面向**小学三年级（北师大版上册）**学生的游戏化数学练习 Web 应用。孩子在一座可自由行走的 3D 广场里养宠物、种庄稼、抽装扮，而数学题是获取这一切游戏资源的门票。

### 1.2 参考产品
学而思"数学天天练"（3D 广场、宠物养成、农场、抽卡体系）；交互与视觉参考洪恩（趣味）、斑马（IP 角色）、Khan Kids（简洁明亮）。

### 1.3 目标用户与设备
- 小学三年级学生（8–9 岁），家长期望其每天坚持练习口算。
- **目标真机：华为 MatePad 11.5"（型号 TGR-W10，HarmonyOS 4.2.0，8GB RAM，2800×1840），平板横屏**；不做手机竖屏版。
- 交付形态：**PWA 网页应用**（一期无 App、无注册），开发期局域网 HTTP 调试、正式期免费 HTTPS 静态托管。详见 [architecture.md](./design/architecture.md) §部署。

### 1.4 核心价值
不是"做卷子"，而是"养宠物、种庄稼、抽装扮"——把日常练习变成养成经营的资源来源。**宠物养成是第一驱动力（可爱 + 可进化）**。

### 1.5 一期产品骨架（两个枢纽）
- **首页 = 纯 2D 学习枢纽**：只放学习相关内容（练口算、真题大挑战、错题本、每日打卡），并作为进入 3D 世界的入口。
- **广场 = 实时 3D 世界 + 养成 / 经营枢纽**：宠物跟随、浮题快答、农场、学盒抽卡、背包换装、宠物面板、每日宝箱。
- **除广场外全部页面都是 2D**，不做实时 3D。

## 2. 核心游戏循环

```
首次进入：主角亮相 + 起名 → 领养雪球兔 → 直接进广场游玩
非首次进入：进首页（学习枢纽）

学习产线（首页 / 2D）
  练口算（手写 MNIST）/ 真题大挑战（选择题），20 题一轮
    答对 → 贝壳 + 宠物食物；做完一轮 → 保底贝壳 + 食物
    答错 → 不弹解析，快速进下一题，自动进错题本（可重做）
  每日打卡 → 首页或广场发光宝箱领连学奖励

养成 / 经营产线（广场 / 3D + 2D 面板）
  广场走动，靠近漂浮题 → 拾取 → 5 秒口算三选一 → 得食物 / 贝壳
  喂宠物（一键全部）→ 宠物经验 → 3 级进化
  贝壳 → 学盒抽人物装扮 → 背包 2D 纸娃娃换装
  广场农场建筑 → 2D 农场：种作物 → 真实时间成熟 → 收获 → 卖花朵币 → 买种子
```

## 3. 用户动线与页面地图

### 3.1 首次 / 非首次分流
- **首次进入**：启动加载 → **主角亮相 + 起名**（可跳过、默认"小朋友"）→ **领养宠物**（雪球兔，展示 3 只、犬猫"即将开放"）→ **直接进广场游玩**。
- **非首次进入**：启动加载 → **首页**。
- 不做注册 / 登录；按当前设备分配本地游客身份（UUID 持久化），下次沿用。账号系统二期。

### 3.4 返回规则
- 所有二级页面左上角固定返回，**返回上一级（从哪来回哪去）**，不一律回主场景。
- **答题进行中点返回 → 二次确认**："答题中，确认返回？放弃则本轮进度 / 奖励不保留"。
- 农场 / 抽卡 / 错题本 / 宠物面板 / 设置：直接返回不确认。
- 广场浮题弹窗：超时 / 作答后自动关闭回广场，不确认。

## 5. 模块 2：首页（纯学习枢纽）

- **左列固定区**：主角 2D 立绘（中性 IP、穿当前装扮的纸娃娃合成图，站圆台）+ 宠物（脚边、纯展示氛围）+ **"益智乐园"绿色大按钮（进广场）**。左列角色 / 宠物**仅展示，不可点击跳转换装 / 宠物面板**。
- **右侧 3 张学习卡，手动滑动切换（不自动轮播）**，配圆点指示器：
  1. 连学打卡 + 练口算；
  2. 真题大挑战；
  3. 错题本。
- **顶部栏**：头像（主角 2D）/ 用户名 / 连学天数 / 累计学习天数 / 设置齿轮；"切换教材"一期隐藏（只有北师大三上）；家长中心入口二期加。
- **每日打卡可在首页直接领取**：打卡做成可复用组件 **ChestPanel**，首页连学卡点领取、广场点发光宝箱弹同一面板，每日只领一次；领取后卡片变"已领取，明日再来"。
- **首页不做**：换装、宠物面板、农场、学盒、排行榜、底部 Tab 的任何入口 / 跳转；冒险地图二期。
- **天气**：一期固定白天好天气；游戏内天气系统二期；现实天气播报永不做。

### 6.2 顶部 UI
- 左上：返回首页；**顶部居中：学盒图标入口**（仅图标无文字）。
- 右上：资源胶囊（贝壳 / 花朵币）；食物不进顶部、无体力。

### 6.3 快捷交互
- **广场固定宠物位 + PetBubble 转二期**（组件已备）；一期宠物交互在宠物面板 P9。

- **仓库 = 农场专属**（种子 + 果实），广场不出现。

## 7. 模块 4：答题

### 7.1 一期题型
| 题型 | 形式 | 入口 | 单题奖励 |
|---|---|---|---|
| **练口算** | 手写计算题，MNIST 识别 | 首页卡 1 / 广场答题小屋 | +5 贝壳 |
| ~~真题大挑战~~ | **转二期**（选择题，点选 ABC）；一期保留卡片入口，点击"即将开放" | — | — |
| ~~错题本重做~~ | **转二期**（整页）；一期保留卡片入口，点击"即将开放" | — | — |
| ~~广场浮题~~ | **已取消**（2026-10-04；产出并入口算结算） | — | — |

- 命名："校内大挑战"统一改为 **"真题大挑战"**；"学奥数"二期。
- **填空题、应用题（含手写最终答案）、学奥数均二期。**

### 7.2 出题节奏
- 一期仅口算单题型：**一轮 20 题，做完即结算（与正确率无关）；正式答题不设超时**。
- **答题中返回一律二次确认**（"放弃则本轮进度/奖励不保留"）；退出后**从哪来回哪去**（广场进则回广场、首页进则回首页）。
- 掌握度出题 / 开学小测 / 错题自动收录**转二期**：一期口算生成器按已解锁知识点路径出题（掌握度骨架与未解锁过滤保留，配比 70/30 不启用）。

### 7.3 手写识别（一期只服务练口算）
- 流程：手写 → MNIST 识别 → 直接判定对错。
- **"回显识别数字 + 逐格确认 / 修改"仅调试模式**（可配置开关、默认关），用于排查识别问题。
- 空白 / 没识别出来：提示"再写一次"。
- 已知取舍：识别误判会按错题计入，靠错题本重做正确移出兜底。
- **手写样本采集（转二期，一期不采集）**：二期起每次提交把"笔迹栅格图 + 识别数字 + 正确答案 + 对错"存本地 IndexedDB；识别 ≠ 正确答案标"待复核 / 潜在识别错误"、可导出，人工区分"算错 vs 识别错"后用于后续再训练。一期无后端，"识别有误"快捷反馈入口二期。
- 模型策略：**当前使用第一版 MNIST 模型（测试集 97.35%），不无条件重训**；仅当出现明显 / 高频误判，或积累足够真实儿童手写样本后再重训。训练 / 转换流程见 `ml/mnist/README.md`。

### 7.4 错题处理
- 答错当场**不弹解析 / 答案**，保留错误值可重写，轻量反馈。
- **一期静默预采集**：答错照常写入 wrongbook 表（"知识点 + 题型"去重，上限 100 条、淘汰最旧），但无展示入口，结算页不再出现错题本按钮；二期开放错题本页面。strokes 表 schema 保留不删、一期不写入（手写样本采集二期，见 §7.3）。

### 7.5 结算
- **2026-10-05 经济回调**：贝壳 = 答对题数 × 单题（口算 5），**取消完成保底**（全部并入单题）；宠物食物 **+5** / 轮。
- 展示真实贝壳 / 食物 + 连学天数；流程仅全部答对才结算，不显示"答对 X/N"。
- **每日奖励上限**：每日前 **2 轮**全额发放（含食物），之后仍可无限练习但**不发任何奖励**（练习轮结算页明确提示"无奖励"）。
- 按钮：主"再练一轮"（新轮）+ 次"回首页"。
- 视觉：白雏鸟举星欢呼、"太棒啦"、奖励行。

### 7.6 题库与内容生产
**来源原则**
- 不直接爬取商业教辅 / 题库站（试题具体文字表达有版权、多登录付费反爬、清洗成本高）。
- 不受版权保护的是"题型 / 知识点 / 解题方法"，受保护的是"具体文字表达"；可把真题当教研参考再**原创改编**（换情境、换数字，不照抄）。
- 开源数据集 Ape210K / Math23K 多为学术 / 非商用 License，仅作参考；名校真题库正版授权二期。

**一期两类题、全部程序自动生成、无需人工题库、不爬取**
- **练口算 = 100% 程序生成**：按知识点配置运算类型 / 数字范围 / 进退位 / 括号 / 步数，代码计算答案，无限量、答案 100% 准，MNIST 手写。
- **真题大挑战 = 仅选择题、自动生成**：计算结果选择 + 可选择化的概念辨析；干扰项按典型错误规则生成（进位 / 退位 / 数位 / 运算顺序错）；点选 ABC、不手写。**概念辨析用"有限模板库 + 参数填充"，模板须经教研（用户）审核，不做纯随机**，保证题目严谨。
- **广场浮题**：简单口算三选一，复用口算生成器、低难度、5 秒。

**生成前提：先建《一期知识点 - 题型 - 解法清单》**
依据北师大三上教材目录 + 课标（公开无版权），逐知识点列出：教学顺序路径、题型、参数范围、运算规则、标准解法分步、典型易错点、掌握阈值。生成器据此出题，错题本分步思路也由它驱动。（助手起草、用户审核，为 M0 / M1 待办输入。）

**一期去除（不适合自动生成 / 当前场景）**：观察物体（空间视图配图）、作图 / 测量操作、里程表复杂情境、"数学好玩"综合实践；填空、应用题、奥数二期。

**北师大三上一期知识点覆盖（沿有序路径）**
- 计算（程序生成、全覆盖）：混合运算（乘加乘减 / 除加除减 / 带小括号）、加与减（连加连减 / 加减混合；里程表情境题二期）、乘与除（整十整百 × 一位数 / 两位数 × 一位数 / 除数一位数口算）、乘法（两三位 × 一位数 / 含 0 / 连乘）、小数简单加减。
- 概念辨析（选择题、有限模板）：周长（公式 / 长短比较 / 给长宽求周长）、年月日（大小月 / 平闰年 / 简单日期与 24 时）、小数（读写 / 比大小）、运算顺序（先算什么 / 括号作用）。

### 7.7 出题推进机制：知识点有序路径 + 掌握度
替代"全册随机 / 手动选单元 / 纯日历周历"。
- 把三上保留知识点排成一条**有序路径**（混合运算 → 加与减 → 乘与除 → 乘法 → 周长 → 年月日 → 小数 …），每个知识点三态：**未解锁 / 学习中 / 已掌握**。
- **推进规则**：当前知识点在答题中累计 / 连续答对达到阈值（默认 **3–5 次、可配置**）即标记"已掌握"，**自动解锁下一个知识点**；答错则该知识点继续出现，并插入相关前置知识点复习。
- **每轮 20 题配比**：当前"学习中"知识点约 **70%** + 已掌握知识点复习约 **30%**；**未解锁知识点不出题 → 天然不超纲**。
- 进度由掌握情况驱动、不被日历锁死：熟练孩子连续掌握即自动加速、能追上学校进度；吃力孩子停在当前知识点反复练、不掉队。

## 17. 里程碑（概要）

- **M0 地基与设计固化**：文档定稿、tokens / 画风 / prompt 库、PWA 骨架、UI 组件、知识点路径 + 题库 schema + 掌握度引擎骨架、数值 config、HTTPS 托管。
