## 1. 产品概述

### 1.1 定位
面向**小学三年级（北师大版上册）**学生的游戏化数学练习 Web 应用。孩子在一座可自由探索的广场里养宠物、种庄稼、抽装扮，而数学题是获取这一切游戏资源的门票。

### 1.2 参考产品
学而思"数学天天练"（广场、宠物养成、农场、抽卡体系）；交互与视觉参考洪恩（趣味）、斑马（IP 角色）、Khan Kids（简洁明亮）。

### 1.3 目标用户与设备
- 小学三年级学生（8–9 岁），家长期望其每天坚持练习口算。
- **目标真机：华为 MatePad 11.5"（型号 TGR-W10，HarmonyOS 4.2.0，8GB RAM，2800×1840），平板横屏**；不做手机竖屏版。
- 交付形态：**PWA 网页应用**（一期无 App、无注册），开发期局域网 HTTP 调试、正式期免费 HTTPS 静态托管。详见 [architecture.md](./design/architecture.md) §部署。

### 1.4 核心价值
不是"做卷子"，而是"养宠物、种庄稼、抽装扮"——把日常练习变成养成经营的资源来源。**宠物养成是第一驱动力（可爱 + 可进化）**。

### 1.5 一期产品骨架（两个枢纽）
- **首页 = 纯 2D 学习枢纽**：只放学习相关内容（练口算、真题大挑战、错题本、每日打卡），并作为进入广场的入口。
- **广场 = 2D 静态页 + 养成 / 经营枢纽**：整页背景 + 热点，承载宠物面板、农场、学盒抽卡、背包换装等入口（实时 3D 广场转二期）。
- **一期全部页面均为 2D**，不做实时 3D。

## 2. 核心游戏循环

```
首次进入：主角亮相 + 起名 → 领养雪球兔 → 直接进广场游玩
非首次进入：进首页（学习枢纽）

学习产线（首页 / 2D）
  练口算（手写 MNIST），20 题一轮
    答对 → 贝壳；答错 → 不弹解析，快速进下一题，自动记录错题数据（一期无展示入口）
    做完一轮 → 宠物食物（每日前 2 轮全额发奖励，之后练习轮无奖励）
  每日打卡 → 首页连学卡领连学奖励

养成 / 经营产线（广场 / 2D + 2D 面板）
  喂宠物（一键全部）→ 宠物经验 → 3 级进化
  贝壳 → 学盒抽人物装扮 → 背包 2D 纸娃娃换装
  广场农场建筑 → 2D 农场：种作物 → 真实时间成熟 → 收获 → 卖花朵币 → 买种子
```

## 3. 用户动线与页面地图

### 3.1 首次 / 非首次分流
- **首次进入**：启动加载 → **主角亮相 + 起名**（可跳过、默认"小朋友"）→ **领养宠物**（雪球兔，展示 3 只、犬猫"即将开放"）→ **直接进广场游玩**。
- **非首次进入**：启动加载 → **首页**。
- 不做注册 / 登录；按当前设备分配本地游客身份（UUID 持久化），下次沿用。账号系统二期。

### 3.4 返回规则
- 所有二级页面左上角固定返回，**返回上一级（从哪来回哪去）**，不一律回主场景。
- **答题进行中点返回 → 二次确认**："答题中，确认返回？放弃则本轮进度 / 奖励不保留"。
- 农场 / 抽卡 / 错题本 / 宠物面板 / 设置：直接返回不确认。

## 5. 模块 2：首页（纯学习枢纽）

- **左列固定区**：主角 2D 立绘（中性 IP、穿当前装扮的纸娃娃合成图，站圆台）+ 宠物（脚边、纯展示氛围）+ **"益智乐园"绿色大按钮（进广场）**。左列角色 / 宠物**仅展示，不可点击跳转换装 / 宠物面板**。
- **右侧 3 张学习卡，手动滑动切换（不自动轮播）**，配圆点指示器：
  1. 连学打卡 + 练口算（打卡领取入口在本卡内）；
  2. 真题大挑战（一期点击"即将开放"）；
  3. 错题本（一期点击"即将开放"）。
- **顶部栏**：头像（主角 2D）/ 用户名 / 连学天数 / 累计学习天数 / 设置齿轮；"切换教材"一期隐藏（只有北师大三上）；家长中心入口二期加。
- **每日打卡可在首页直接领取**：打卡做成可复用组件 **ChestPanel**，首页连学卡点领取，每日只领一次；领取后卡片变"已领取，明日再来"（广场 3D 发光宝箱弹同一面板，二期）。
- **首页不做**：换装、宠物面板、农场、学盒、排行榜、底部 Tab 的任何入口 / 跳转；冒险地图二期。
- **天气**：一期固定白天好天气；游戏内天气系统二期；现实天气播报永不做。

## 6. 模块 3：广场（2D 静态页）

> 广场 = 整页 2D 背景 + 热点，人物不可移动；实时 3D 广场转二期（[plaza-3d.md](./design/plaza-3d.md) 留档）。

### 6.1 建筑与热点
- 整页 2D 背景（以 plaza-v2.jpg 为准），建筑不可移动，点击热点进下游：
  - **答题小屋 → 答题 P6**；**农场建筑 / 右下农场圆钮 → 农场 P8**；右下宠物圆钮 → 宠物面板 P9；右下背包圆钮 → 背包 P16。
  - **宠物商店**：占位"即将开放"。
- 许愿池一期不出场（二期）。

### 6.2 顶部 UI
- 左上：返回首页；**顶部居中：学盒图标入口**（仅图标无文字）。
- 右上：资源胶囊（贝壳 / 花朵币）；食物不进顶部、无体力。

### 6.3 快捷交互
- **广场固定宠物位 + PetBubble 转二期**（组件已备）；一期宠物交互在宠物面板 P9。
- **广场不出现漂浮题**：食物 / 贝壳产出并入口算结算（每日前 2 轮全额、之后练习轮无奖励，见 §13.3）。
- 每日宝箱：一期仅在首页连学卡打开 ChestPanel（广场 3D 发光宝箱二期）。

### 6.4 仓库 / 背包边界
- **仓库 = 农场专属**（种子 + 果实），广场不出现。
- **背包 = 人物装扮**，从广场右下圆钮进入。

## 7. 模块 4：答题

### 7.1 一期题型
| 题型 | 形式 | 入口 | 单题奖励 |
|---|---|---|---|
| **练口算** | 手写计算题，MNIST 识别 | 首页卡 1 / 广场答题小屋 | +5 贝壳 |

- 真题大挑战（选择题）、错题本重做转二期（见 [PRD-v2.md](./PRD-v2.md)）；一期保留首页卡片入口，点击"即将开放"。
- **填空题、应用题（含手写最终答案）、学奥数均二期。**

### 7.2 出题节奏
- 一期仅口算单题型：**一轮 20 题，做完即结算（与正确率无关）；正式答题不设超时**。
- **答题中返回一律二次确认**（"放弃则本轮进度 / 奖励不保留"），退出后从哪来回哪去（见 §3.4）。
- 掌握度出题完整机制 / 开学小测 / 错题本功能**转二期**：一期口算生成器按已解锁知识点路径出题（路径骨架与未解锁过滤保留，见 §7.7）；答错仅做数据层记录（见 §7.4）。

### 7.3 手写识别（一期只服务练口算）
- 流程：手写 → MNIST 识别 → 直接判定对错。
- **"回显识别数字 + 逐格确认 / 修改"仅调试模式**（可配置开关、默认关），用于排查识别问题。
- 空白 / 没识别出来：提示"再写一次"。
- 已知取舍：识别误判会按错题计入（一期无纠正出口，由 100 条上限 + 淘汰限幅；二期错题本上线后靠重做正确移出兜底）。
- **手写样本采集转二期，一期不采集**：strokes 表 schema 保留、一期不写入；二期方案见 [PRD-v2.md](./PRD-v2.md)。
- 模型策略：**当前使用第一版 MNIST 模型（测试集 97.35%），不无条件重训**；仅当出现明显 / 高频误判，或积累足够真实儿童手写样本后再重训。训练 / 转换流程见 `ml/mnist/README.md`。

### 7.4 错题处理（一期写而不显）
- 答错当场**不弹解析 / 答案**，保留错误值可重写，轻量反馈。
- **一期仅数据层记录**：答错写入 **wrongbook** 表，字段 = 知识点 + 题型 + 错误答案 + 错误次数 + 时间戳；按"知识点 + 题型"去重、上限 100 条、淘汰最旧。
- **一期无任何展示出口**：无错题本页面、无重做，结算页不出现错题本入口；首页 / 广场错题本入口点击"即将开放"。错题本功能（页面 / 重做 / 移出）见 [PRD-v2.md](./PRD-v2.md)。

### 7.5 结算
- 20 题全部答完才进入结算（与正确率无关）；结算数值（贝壳 / 食物 / 每日上限）见 §13.4。
- 展示本轮真实所得（贝壳 / 食物）+ 连学天数，不显示"答对 X/N"。
- 每日前 2 轮全额发放，之后仍可无限练习但不发任何奖励；练习轮结算页明确提示"无奖励"。
- 按钮：主"再练一轮"（新轮）+ 次"返回"（从哪来回哪去，见 §3.4）。
- 视觉：白雏鸟举星欢呼、"太棒啦"、奖励行。

### 7.6 题库与内容生产
**来源原则**：不直接爬取商业教辅 / 题库站（试题具体文字表达有版权、反爬与清洗成本高）；题型 / 知识点 / 解题方法不受版权保护，可参考真题**原创改编**（换情境、换数字，不照抄）；开源数据集仅作参考，名校真题库正版授权二期。

**一期全部程序自动生成、无需人工题库、不爬取**
- **练口算 = 100% 程序生成**：按知识点配置运算类型 / 数字范围 / 进退位 / 括号 / 步数，代码计算答案，无限量、答案 100% 准，MNIST 手写。
- 真题大挑战（选择题自动生成 + 干扰项规则 + 概念辨析模板库）转二期，见 [PRD-v2.md](./PRD-v2.md)。

**生成前提：先建《一期知识点 - 题型 - 解法清单》**
依据北师大三上教材目录 + 课标（公开无版权），逐知识点列出：教学顺序路径、题型、参数范围、运算规则、标准解法分步、典型易错点、掌握阈值。生成器据此出题（错题本分步思路二期亦由它驱动）。

**一期去除（不适合自动生成 / 当前场景）**：观察物体（空间视图配图）、作图 / 测量操作、里程表复杂情境、"数学好玩"综合实践；填空、应用题、奥数二期。

**北师大三上一期知识点覆盖（沿有序路径）**
- 计算（程序生成、全覆盖）：混合运算（乘加乘减 / 除加除减 / 带小括号）、加与减（连加连减 / 加减混合；里程表情境题二期）、乘与除（整十整百 × 一位数 / 两位数 × 一位数 / 除数一位数口算）、乘法（两三位 × 一位数 / 含 0 / 连乘）、小数简单加减。
- 概念辨析（选择题、有限模板）转二期，见 [PRD-v2.md](./PRD-v2.md)。

### 7.7 出题顺序：知识点有序路径
替代"全册随机 / 手动选单元 / 纯日历周历"。
- 把三上保留知识点排成一条**有序路径**（混合运算 → 加与减 → 乘与除 → 乘法 → 周长 → 年月日 → 小数 …），知识点三态骨架：**未解锁 / 学习中 / 已掌握**；**未解锁知识点不出题 → 天然不超纲**。
- 一期推进从简：默认从第 1 单元起步；当前知识点答对累计达阈值（默认 **3–5 次、可配置**）即标记"已掌握"并解锁下一个；答错则继续出当前知识点。
- 掌握度完整机制（每轮 70/30 复习配比、答错插入前置知识点复习、开学小测定位起点、学期日历参考尺）转二期，见 [PRD-v2.md](./PRD-v2.md)。

## 8. 模块 5：宠物养成

### 8.1 宠物与形象
- **宠物只有一个 Q 版形象、不换装，宠物装备系统彻底取消**（无装备 tab、无装备槽）。
- 完整版规则：可养多只宠物、同时仅 1 只跟随 / 出战；**一期仅初始领养雪球兔 1 只**，宠物商店 / 获得新宠物二期。
- 宠物为**双足直立卡通萌兽**（非四足）；广场跟随 / 气泡互动转二期，一期宠物交互在宠物面板 P9。

### 8.2 成长（3 级、2 次形态变化）
- 幼崽 → 小变化 → 成年；累计经验阈值与食物换算见 §13.5。
- 一期需该宠物 3 阶段资产（同一基础模型改版，详见资产文档）。

### 8.3 喂食
- **一键全部**：点喂食把当前食物一次全喂出（不逐个点），经验一次结算 + 喂食动画；食物数量只在喂食按钮上方气泡显示。
- 一键喂食若一次跨多级：**只播放"最终到达形态"的一次进化仪式**（中间形态不重复播）。

### 8.4 进化预览（让孩子知道能升级、想升级）
- **进化阶段轨道**：3 阶段缩略图用箭头串链；已解锁正常显示，**未解锁 = 灰度 / 半透明彩色形态 + 锁角标**（能看出长啥样、明显未获得，不用黑影剪影）；点未解锁提示"再喂 X 食物 / 升到 Lv.X 解锁"。
- 喂食按钮附近显示"还差 X 经验 / 食物进化"，临近提示"快要进化啦！"。
- 两个维度区分：**进化轨道 = 当前宠物成长阶段（纵向）**；**右侧两列 = 不同宠物种类（横向、拥有 / 加锁）**。
- **进化仪式**：一键喂食跨阈值 → 光柱光效包裹 → 切换形态 → 星星彩带 + "进化成功！"（不无声切换）。

### 8.5 反应与互动
- 答题页用小宠物角标 / 头像表情（答对欢呼、答错低头）。
- 无独立"玩耍"按钮，**点击宠物形象**即互动（蹦跳 + 冒爱心 / 星星 + 开心话，无消耗无数值），首次弹"点点我呀~"引导；删除亲密度红心。
- **改名**：左下角入口、弹窗输入、可随时免费改、最多 6 字（本地、一期不做敏感词过滤）。

### 8.6 宠物面板布局

- 左下角：改名入口。
- 右侧：两列全部宠物（拥有可切换跟随，未拥有加锁；一期仅初始兔拥有，犬猫"即将开放"）。
- 顶部："宠物 PK"入口（二期设计，一期占位 / 不做功能）。

## 10. 模块 7：农场（2D 俯视）

- 形态 = **2D 俯视**、对齐 farm-v2.png；不做 3D 海岛（水面 / 木栈道码头 / 鳄鱼等一期不做）；不放蓝衣向导（白雏鸟轻提示）。
- 布局：左上返回 + 资源（花朵币 / 贝壳，**无水滴**）、中部耕地、右下种子袋 / 动作按钮。

### 10.1 冷启动
新用户**赠送 2 份玉米种子**（最低等级、直接进仓库种子 tab），**不送花朵币**；靠 2 份玉米种下 → 收获售卖得花朵币 → 再买种子完成自循环。

### 10.2 作物（6 种，以种子面板为准）
| 作物 | 解锁农场等级 | 生长(分) | 收获 XP | 种子价 | 产量 | 售价/个 | 单次净利 |
|---|---|---|---|---|---|---|---|
| 玉米 | 1 | 1 | 3 | 5 | 3 | 3 | 4 |
| 南瓜 | 2 | 3 | 5 | 10 | 2 | 8 | 6 |
| 土豆 | 3 | 5 | 8 | 20 | 2 | 15 | 10 |
| 胡萝卜 | 5 | 8 | 12 | 35 | 2 | 25 | 15 |
| 番茄 | 7 | 12 | 18 | 55 | 2 | 40 | 25 |
| 草莓 | 10 | 15 | 25 | 80 | 1 | 150 | 70 |

- 移除旧稿的菊花 / 郁金香；保证 售价 × 产量 > 种子价。

### 10.3 耕地与解锁
**一期固定 2×2 = 4 块**（对齐 farm-v2 高保真；原 Lv2→6 / Lv4→8 / Lv6→9 扩地与花币扩地均转二期）。
农场累计 XP：Lv1=0 / Lv2=20 / Lv3=50 / Lv4=100 / Lv5=170 / Lv6=260 / Lv7=370 / Lv8=500 / Lv9=660 / Lv10=850（等级用于作物解锁）。

### 10.4 播种与生长
- **先点空地 → 打开种子面板 → 选种播种**。
- 种子需等级解锁，并**按份用花朵币购买、有库存**（种子 tab 显示持有数量，播 1 块地耗 1 份；数量不足时面板内可直接"购买并播种"）。
- **生长用真实时间戳**：种下记录时间，退出 / 离线也按真实时间成熟（一期接受改设备时间）；**分钟级、可配置、地块显示成熟倒计时**（时间见上表）。
- **水滴 / 浇水 / 施肥加速全部二期，一期不做水滴**（顶部不显示、所有奖励表中去掉水滴）。
- 无枯萎机制，成熟后停留等待收获。

### 10.5 收获、售卖与仓库
- 成熟点击收获 → 果实进仓库果实 tab；售卖果实得花朵币（支持选数量 / 一键卖出）。
- **花朵币一期唯一消费 = 购买种子**（装饰 / 扩地二期）。
- **仓库（农场专属）**：一期两 tab = 种子 + 果实；工具 tab 二期；广场不出现仓库。

## 13. 数值配置总表（默认值，全部进 config）

> 所有数值集中到 config 文件、禁止写死业务代码；**正文各模块只写规则，数值一律以本章为准**。上线前跑 7 天 / 30 天产出消耗模拟。一期不做体力 / 水滴。

### 13.1 新用户初始资源
贝壳 0、花朵币 0、食物 0；**赠送 2 份玉米种子**；默认着装 1 套、初始雪球兔 1 只。

### 13.2 货币产出 / 消耗
| 货币 | 产出 | 消耗 |
|---|---|---|
| 贝壳 | 口算 +5/题（**每日前 2 轮全额**）、每日宝箱 | 学盒抽卡 单抽 50 / 十连 450 |
| 花朵币 | 农场卖果实 | 一期仅买种子（装饰 / 扩地二期） |
| 宠物食物 | 完成一轮 +5（**每日前 2 轮**）、每日宝箱 | 喂食（1 食物 = 10 经验） |

### 13.3 刷题每日奖励上限
每日前 **2 轮**全额发贝壳 / 食物，之后可无限练习但**零奖励**（练习轮结算页提示"无奖励"）；N 可配置。

### 13.4 答题结算
贝壳 = 答对数 × 单题（口算 5）；**无完成保底**；食物 +5/轮；20 题 / 轮、做完即结算（与正确率无关）；正式答题不超时。

### 13.5 宠物成长
1 食物 = 10 经验；Lv.1 幼崽 0 → Lv.2 累计 50（5 食物）→ Lv.3 成年累计 1000（100 食物，按每日 2 轮答题 + 每日宝箱满产约 5–7 天）；无装备槽。

### 13.6 抽卡
单抽 50 / 十连 450；普通 75 / 稀有 20 / 传说 5；保底 10 抽稀有 / 100 抽传说、本地持久化；每次必出一件；重复提示"已有"、不返贝壳。

### 13.7 每日宝箱（连学）
| 宝箱等级 | 连学天数 | 奖励 |
|---|---|---|
| Lv.1 | 第 1 天 | 10 贝壳 + 2 食物 |
| Lv.2 | 连 2 天 | 15 贝壳 + 4 食物 |
| Lv.3 | 连 3 天 | 25 贝壳 + 8 食物 |
| Lv.4 | 连 5 天 | 40 贝壳 + 14 食物 |
| Lv.5 | 连 7 天及以上 | 60 贝壳 + 24 食物 |

每日一次，首页连学卡领取（广场 3D 发光宝箱二期）；不断签保持 Lv.5。

### 13.8 连学机制
- 打卡条件：当天**完成 ≥1 轮正式答题（口算 20 题）**即"今日学习达成"；达成后当日宝箱可领、连续天数 +1。
- 两个指标：**连续天数 streak**（中断重置、决定宝箱等级）；**累计学习天数**（历史总天数、不清零、首页顶部展示）。
- 断签：某天未完成则连续中断、宝箱等级降一级（断签降级不清零、累计天数保留）。
- 本地时间戳记录（最后学习日 / 连续 / 累计 / 宝箱等级 / 今日是否已领）；一期无后端、接受改设备时间，云存档二期防作弊。
